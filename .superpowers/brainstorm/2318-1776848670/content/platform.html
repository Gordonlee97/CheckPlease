What kind of app should this be?

This shapes everything — development stack, deployment, and how your friends use it

A

React Native / Expo (Mobile App)

Compiled iOS + Android app. Camera access is first-class, feels native, ships to App Store / Google Play. Best UX but requires store review and users must install it.

Pros

  • Native camera, feels fast
  • Works offline
  • Installable home screen icon

Cons

  • App store submission overhead
  • Friends must install it
  • Separate iOS / Android builds
B

Progressive Web App (PWA)

A website that runs in mobile Safari/Chrome with camera access via the browser. Open a link, done — no install required. Can still be added to home screen.

Pros

  • No install — just share a link
  • One codebase for all platforms
  • Instant updates

Cons

  • Browser camera is slightly slower
  • iOS PWA has some limitations
  • Needs internet for OCR
C

Native iOS (Swift/SwiftUI)

iPhone-only, maximum performance and camera control. Cleanest UX for Apple users but excludes Android friends entirely.

Pros

  • Best possible iOS camera experience
  • Access to latest Apple APIs
  • Fastest performance

Cons

  • iPhone only
  • Requires Xcode + Mac to develop
  • App Store required for distribution
